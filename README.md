# 🧮 Simple Calculator (HTML, CSS, JavaScript)

A clean and modern calculator built using **pure HTML, CSS, and JavaScript**.  
This project is beginner-friendly and perfect for learning DOM manipulation and basic arithmetic logic.

---

## 🚀 Features

- Responsive calculator layout
- Dark theme UI
- Supports:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
- Clear (C) button
- Decimal support
- Keyboard-free UI interaction
